# global-view-viewswitch

全球控制面详情页方案实现，当前包含已调整完成的方案三视图切换与级联下拉交互。

## 本地运行

```bash
PATH=/opt/homebrew/bin:$PATH npm run dev
```

## 本地构建

```bash
PATH=/opt/homebrew/bin:$PATH npm run build
```

## 发布信息

- GitHub Repo: `https://github.com/hyin9412/global-view-viewswitch`
- GitHub Pages: `https://hyin9412.github.io/global-view-viewswitch/`
- 发布方式：本地构建后，将源码推送到 `main`，将 `dist/` 目录发布到 `gh-pages`

## Pages 说明

本项目使用 Vite，生产环境 `base` 已配置为 `/global-view-viewswitch/`，用于适配 GitHub Pages 子路径部署。
